Try it. It is not a screenshot.

This is the interface rebuilt in the browser: press the buttons, drag the sliders, type in the field, capture a keybind, open the palette with Ctrl+K, switch tabs, collapse a section, throw a notification. Every interaction below maps to a component in src/, and the press feedback, timings and keyboard model are the library's.

Interface

Meta

Buttons

Seven variants, three sizes. Every press fires a pointer-anchored ripple, a 0.965 scale, a colour step and an optional cue.

▾

Press and hold: the ripple starts under the pointer and expands to the furthest corner. Release outside and it cancels — the library tracks the pointer, not the button.

Toggles and segmented

A spring-driven knob and a sliding indicator, both owned by the motion engine so they can never desync.

Sliders

Drag, click, arrow keys, Home/End. Shift multiplies the step. Values are snap-rounded to their step and the readout is formatted from the same number the callback receives.

Focus a slider and press Home / End, then arrow keys — hold Shift for coarse steps. This is the same keyboard model the Luau component implements.

Notifications

Queued, counted, hover-paused. Same Key groups instead of stacking, and actions become buttons inside the toast.

▾

Hover a toast and its countdown rail pauses; click it to dismiss. The rail is generated from the same duration the queue uses, not a hardcoded animation.

Modal

Backdrop, Escape, result promise. Confirm and Alert are the two shapes you actually need.

▾

The promise resolves true or false — dismissing with Escape or the backdrop is a false, never a hang.

Command palette

Ctrl+K from anywhere, recents remembered, arrows to move, Enter to run.

▾
Commands include switching the documentation theme, replaying the loading screen, and pushing a notification — so the palette is doing real work here, not a mock list.

One animation engine

Tweens, springs and tickers share a single stepped scheduler. Property ownership means a newer tween on the same property supersedes the older one instead of fighting it.

▾
EasingNamed, from the catalog
DurationRead by the tween, not by the demo 0.45s
The duration readout is the slider's own value, which is what the tween is built from.

In the library this is Motion.tween(instance, { Position = goal, Time = 0.45, Easing = "emphasize" }). Springs are a separate primitive that runs at a fixed 1/240 s sub-step, so stiffness stays stable regardless of frame rate.

Reduced motion

When the player asks for less motion, the engine still runs — it quantises to endpoints instead of deleting feedback, so nothing becomes unresponsive.

▾
Motion.setReducedMotion(true)Animations land instantly; presses, ripples and state changes remain.

The loading screen is the part players remember

The mark is sliced into bands and every band is offset by a travelling sine wave — a moving filter over the image, not a fade. The bleed for each band is computed from the amplitude and frequency, which is why the slices never show seams. The mark is anchored to the bottom-right of the safe area, above the interface, never inside it.

Preparing

Reading configuration

0%

Press {TOGGLE} at any time to show or hide the interface.

My Gamev1.0.0
Auto-continue after preloading — in the library this is AutoContinue = 2.4; turn it off and the screen waits for the player.

Honest note: in the browser there is no ContentProvider, so the percentage here is simulated at a fixed rate. In Roblox the same bar is driven by ContentProvider:PreloadAsync against the asset list you pass in, weighted by phase, with stall detection when a request goes quiet.

Ten themes, derived — not hand-picked

Each theme is a seed: an accent hue, a mode and a temperature. Surfaces, borders, the four semantic colours and the shadow are derived from it with contrast targets enforced in CI. The house theme is Obsidian — warm charcoal with an amber accent, deliberately not blue.

Clicking a card rethemes this entire page, including the window above — the same live token swap the library performs, which is why nothing flashes when you switch.

The easing catalog, plotted from source

These curves are evaluated from a line-by-line port of src/Core/Easing.luau, including its Newton-Raphson cubic-bezier solver. Hover or click a card to run the dot along the function the library would use.
